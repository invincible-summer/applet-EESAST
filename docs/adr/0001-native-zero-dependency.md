# ADR-0001：采用原生微信小程序与零运行时依赖

- 状态：Accepted
- 日期：2026-09-23
- 影响范围：工程技术路线、构建和依赖管理

## 背景

EESAST 的已有门户使用 React，而小程序需要原生分包、TabBar、暗色模式、rpx 和微信生命周期能力。跨端框架无法直接复用现有 Ant Design 和 styled-components 组件，仍需要重写移动端 UI。

## 决策

使用原生 WXML、WXSS、JavaScript 和 CommonJS 模块；不引入 npm 运行时依赖和构建步骤。仓库根目录可以直接被微信开发者工具导入。

## 结果

- 克隆后无需安装依赖即可预览，升级基础库时不受构建链锁定。
- 页面必须遵循小程序页面注册、分包和组件路径规则。
- SHA-1/HMAC-SHA1、JWT、Markdown 和 COS 签名由 `utils/` 中的轻量实现负责。
- 复杂通用逻辑要保持纯 JS，并通过脚本验证；若未来需要构建链，先新增 ADR 说明迁移成本和发布影响。
