# ADR-0002：按领域分包并用页面轮询替代订阅

- 状态：Accepted
- 日期：2026-09-23
- 影响范围：包体、页面导航、实时数据刷新

## 背景

TabBar 页面必须进入主包，赛事、信息化和资源功能又包含较多深层页面。Web 端的 GraphQL Subscription 在小程序后台切换和网络恢复场景下不够稳定，且会增加协议实现成本。

## 决策

- 主包只放五个 Tab 页面和登录、注册、找回密码等账号流程。
- `packages/contest`、`packages/info`、`packages/share` 按领域拆分深层页面。
- 赛事编译状态、对战房间和导师消息使用页面生命周期控制的轮询；`onShow` 启动，`onHide` / `onUnload` 停止。
- `app.json` 的 `preloadRule` 只为进入领域页的 Tab 预加载对应分包。

## 结果

页面首屏和主包体积更可控，轮询逻辑更容易调试；实时性由固定间隔和页面可见性共同决定。新增页面必须先判断属于主包还是现有分包，不能为单个功能随意新增分包。
