# ADR-0004：COS 使用后端发放的临时凭证

- 状态：Accepted
- 日期：2026-09-23
- 影响范围：头像、代码、附件和回放上传下载

## 背景

小程序需要访问腾讯云 COS，但永久密钥不能进入客户端。现有 API 已能根据路径前缀和用户角色发放 STS 临时凭证。

## 决策

- 所有 COS 操作先通过 API 获取对应前缀的临时凭证。
- 客户端只在内存中使用 STS，凭证接近过期时重新获取。
- 上传、列表、HEAD 和预签名下载统一复用 `utils/cos.js` 与自实现签名模块。
- 对战回放下载先用 HEAD 探测对象；不存在时向用户说明，不复制死链。

## 结果

客户端不保存永久密钥，路径权限由服务端按前缀收敛；新增 COS 业务必须明确前缀、操作类型和失败提示，并补充签名/回放回归测试。
