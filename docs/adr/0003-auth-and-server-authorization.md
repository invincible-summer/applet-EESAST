# ADR-0003：账号密码认证与服务端最终授权

- 状态：Accepted
- 日期：2026-09-23
- 影响范围：登录、角色拦截、数据访问和隐私

## 背景

现有 API 没有微信 `code2session` 登录接口，而修改后端不在小程序仓库范围内。现有 JWT、Hasura 行级权限和 REST 角色校验已经能覆盖网页端账号体系。

## 决策

- v1 使用现有用户名/邮箱加密码登录，并保留匿名 token 读取公开数据。
- JWT 存微信沙箱；验证码 token 只存页面内存；密码不持久化。
- 前端用 `userRoles` 和 `tsinghuaRoles` 做体验层拦截，服务端 REST 校验和 Hasura 行级权限是最终授权边界。
- 不在小程序内提供全局用户搜索、管理端写操作或危险广播/无鉴权上传端点。

## 结果

用户可以复用网页端账号，公开页面可匿名访问；微信一键登录需要未来在 API 仓库新增接口后再单独评估。任何客户端权限判断都不能被视为安全边界。
