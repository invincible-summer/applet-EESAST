# 真机 / 开发者工具验收清单

> 适用版本：EESAST 小程序 v1 + 「联调修复」PR（#1 / #2）
> 更新日期：2026-10-21
> 目标：在**开发者工具**与**真机**上把登录态相关流程走通，补充自动化脚本覆盖不到的部分。

自动化脚本能覆盖语法、结构、绑定、签名与纯函数，但**覆盖不到真实账号、真实数据、真实网络与渲染**。本清单就是那部分。

## 4. 常见错误码速查

| 状态码 | 含义 | 常见位置 |
|---|---|---|
| 401 | token 失效 / 验证码错误 | 任意接口；登录、改密、注销 |
| 403 | 角色无权限 / 不在队伍中 | 信息化、组队、代码 |
| 404 | 资源不存在 | 公告/附件/回放 |
| 409 | 重复（荣誉申请、编译中） | 荣誉、代码编译 |
| 429 | 频率限制 / LLM 限流 | 导师申请、LLM |
| 450 / 451 | 参数缺失 / 角色不符 | 荣誉接口 |
| 551 | 队伍成员已满 | 组队加入 |
| -1 | 网络失败（`wx.request` fail） | 断网、域名未配置 |

> 真机上如果所有请求都失败，优先检查：**服务器域名白名单**、HTTPS 证书、以及手机网络是否被校园网客户端隔离。

## 6. 提交前自动化校验

```bash
node scripts/test_structure.cjs      # 页面/导航/事件处理器/组件路径
node scripts/test_wxml_balance.cjs   # WXML 标签闭合
node scripts/test_bindings.cjs       # WXML ↔ JS 绑定一致性
node scripts/test_utils.cjs          # SHA1/JWT/Markdown/SSE
node scripts/test_cos_signature.cjs  # COS 签名（有 SDK 时与官方实现逐字节比对）
```

CI（`.github/workflows/ci.yml`）会在每次 push / PR 自动执行以上检查。
