## 发布记录

发布新版本时：

1. 在本文件更新当前版本和历史表。
2. 在 [releases/CHANGELOG.md](./releases/CHANGELOG.md) 添加版本条目。
3. 运行 [TESTING.md](./TESTING.md) 中的自动化和真机验收。
4. 创建 Git 标签，例如 `v1.2.0`，并记录体验版或正式版构建信息。
