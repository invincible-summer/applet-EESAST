# 变更记录

版本号遵循 [SemVer](../VERSION.md)。

## [1.2.0-dev] - 2026-10-28

### Added

- 新增规范化文档入口、架构说明、ADR、版本记录和变更日志。
- 首页增加品牌欢迎区、登录状态和部门图文卡片。
- 赛事、信息化、资源和个人中心增加统一的页面标题层级与视觉标记。

### Changed

- 全局配色从靛蓝调整为 EESAST 青绿色，并同步浅色、深色主题。
- 统一卡片、按钮、标签、空状态、宽屏和窄屏布局。
- 赛事详情、课程和 Weekly 卡片增加更清晰的状态与按压反馈。
- README 从旧设计文档链接改为 docs 文档入口。

### Fixed

- 修复微信原生输入框在垂直 padding 与行高叠加时出现的文字裁切。
- 下载对战回放前先探测 COS 对象；没有回放文件时不再复制死链。
- 提升回放权限错误和资源不存在时的提示。

## [1.1.0] - 2026-10-21

- 完成交互审计、Weekly 刷新、赛事状态标签和登录文案对齐。
- 修复赛事时间线、代码提交、导师访问控制、谈话记录下载和课程评论层级。

## [1.0.0] - 2026-09-23

- 发布原生微信小程序 v1，包含五个 Tab、三组分包、账号、赛事、信息化和资源共享能力。
